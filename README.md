# Irrealm - Особиста цифрова бібліотека

**Тема проєкту:** Вебзастосунок для створення та керування особистою цифровою бібліотекою медіаконтенту (книги, фільми, ігри, курси, статті).

**Короткий опис:** 
Irrealm — це платформа, яка допомагає користувачам централізовано зберігати інформацію про контент, який вони споживають. Застосунок дозволяє додавати записи, каталогізувати їх за категоріями, відстежувати прогрес за допомогою статусів ("в процесі", "завершено", "хочу"), а також ставити оцінки та додавати власні теги й нотатки.
